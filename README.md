# Calorie Duo

A lightweight two-person meal and calorie tracker.

Features:
- Two people with separate daily calorie targets.
- Meal logging for Breakfast, Lunch, Snack, Dinner, and Other.
- Calories plus optional protein, carbs, and fat.
- Browse previous/future dates.
- Daily meal history and a 7-day calorie trend.
- Export/import JSON backups for moving data between devices.
- Responsive layout for phones and desktop.

Note: this first version stores data in browser localStorage, so it is not yet real-time cross-device sync.
